Create a minimal standalone CLI application in Go that simulates a Modbus TCP server. The goal is to keep it as simple as possible. It must receive the listening port (e.g., a TCP/UDP port parameter) via command-line flags and log every single Modbus command/request it receives to the standard output. Please recommend and use a reliable Go Modbus library for the server implementation, ensuring the logging clearly shows the register addresses and values being read or written.
