Geographical & Network Layout

The cold chain logistics network is deployed as a hierarchical mesh architecture, cleanly isolating organizational entities from hardware compute gateways.

  • Root Node: Located at Central HQ, performing global system orchestration and state synchronization.
  • Madrid Gateway (node-1): Manages telemetry ingestion for main storage facilities.
  • Barcelona Hub (bindu-minis): Hosts the localized AI edge inference stack running Ollama at 192.168.12.160.
  • Valencia Gateway (bindu-pi3-uno): Monitors dynamic regional sub-compartments.
Architecture Moat: While Ollama is pooled at bindu-minis, each physical node executes its own isolated Semantic Reactor. Prompt synthesis is kept entirely local.

Internal Sandbox Architecture

Every single node implements the exact same lightweight software blueprint, enforcing absolute separation of concerns between raw routing and intelligence.

  • Bindu Core Runner: Manages localized low-latency MQTT message distribution and constructs the v_messages view.
  • BPR Plugin Sandbox: Runs the bindu-semantic-reactor inside a non-blocking, isolated OS process.
  • Go BPR SDK: Secure IPC channel enabling read-only state hydration from the underlying storage primitives.
  • SQLite View (v_messages): Holds high-fidelity timeline facts for contextual prompts.

Semantic Processing Loop

Data streams shift from basic data collection to proactive event processing without brittle hardcoded glue code layers.

FreezerTelemetry

Raw ingestion metrics directly from edge physical devices (temperature, door_open, compressor_current_amps).

StorageRiskAssessment

Cognitive output computed and pushed by the AI Reactor (risk_level, estimated_minutes_to_spoilage, root_cause_prediction).

Real-Time Learning: Because decisions are inherently tied to a Digital Twin ID, the system loops execution logs right back into the context engine automatically.
