Mesh SPA

This tutorial SPA demonstrates the intended browser integration contract: POST /api/v1/messages/sql for historical read-only queries, plus MQTT over wss for live HelloWorldStats. All map data is reconstructed from persisted messages.

The map shows the latest NodeGeoLocation geometry per node. Each time a HelloWorldStats arrives, the page re-runs a grouped query over HelloWorld and overlays the current totals inside the polygon that contains each gateway point.

Geometries come from a SQL query over NodeGeoLocation. The live trigger is HelloWorldStats over MQTT/WSS, but the overlay counts are computed from a fresh grouped query over persisted HelloWorld messages.

How This Demo Works

  1. Load the latest NodeGeoLocation per node with the generic SQL endpoint.
  2. Connect to the public WSS integration endpoint exposed by root.
  3. Subscribe to HelloWorldStats/defaultGroup/+.
  4. Every time a stats message arrives, run a grouped count query on HelloWorld.
  5. Place each total inside the polygon that contains its gateway point. The root total is drawn inside the first polygon returned by the SQL geometry set.
